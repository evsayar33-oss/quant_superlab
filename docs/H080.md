# H080 — All-sector PIT and market-regime research

H080 is a diagnostic continuation of H078/H079, not a new trading strategy.
It retains every event family, including federal grants, awards, contracts,
regulation, energy, chips, critical minerals, AI, infrastructure and capex
where present in the input feed. Missing groups are reported, never discarded.

Run manually in GitHub Actions > H080 — All-sector PIT and regime audit.

Optional offline inputs:
- `--pit-market-cap-file` CSV with `ticker,asof_date,available_at,market_cap_usd`.
  `available_at` must be the verifiable public availability timestamp, not
  merely the fiscal statement date. No modern market-cap backfill is allowed.
  Market-cap provenance, entity identity, revisions, and corporate actions
  must be independently validated before relying on the ratios.
- `--regime-file` CSV with `available_at,regime`; labels must have been
  available before the event date. No hindsight-defined regimes.
- `--feed-file` optional local feed snapshot.

Default Actions run has neither external PIT fundamentals nor regime inputs.
It will still produce category timing/coverage audit and H079/H078 descriptive
results, but **will not pretend** to have tested normalized size or market
regimes. Outputs include H080_REPORT.md, all_family_timestamp_audit.csv,
event_returns_pit_regimes.csv, all_sector_regime_diagnostics.csv and nested
H079/H078 research files.

No trade recommendation is implied. Subsequent strategy validation requires
registered hypotheses, independent chronological holdout, trading costs,
multiple-testing adjustment and out-of-sample robustness.
