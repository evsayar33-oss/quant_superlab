# H079 — Cross-sector event diagnostics

H079 does not replace H078 and does not enable any live strategy. It reuses H078
returns and preserves every event family/category in a separate coverage table.
The study records groups with no measurable prices or insufficient samples
rather than silently removing them.

Run from Actions > H079 — Cross-sector event diagnostics, or locally:

```bash
python scripts/run_h079.py --start 2019-01-01 --max-tickers 600
python -m pytest -q tests/test_h079.py
```

Optional point-in-time fundamentals CSV:

```csv
ticker,asof_date,market_cap_usd
EXAMPLE,2024-01-31,1000000000
```

Use `--pit-market-cap-file path/to/verified.csv` locally only after validating
source provenance, historical availability, security identity, currency,
corporate actions and point-in-time release timing. As-of dates must be strictly
earlier than the event date. The default GitHub workflow does **not** download
current market caps and does not fabricate missing historical market caps.
Until a verified historical dataset exists, `amount_to_cap` stays null.

Artifacts include H078 raw outputs, H079 enriched returns, all-category
coverage, forward-only ingestion observations, excluded timestamp proxies,
sector/category/horizon diagnostics, and a report. The results are descriptive;
no post-hoc candidate selection, p-values or profitability claim is made.
