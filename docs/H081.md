# H081 — Evidence-first research adjudication

This phase closes the **currently testable** H078–H080 research questions without
manufacturing historical data or claiming that an Actions success proves alpha.

1. All Radar event categories are preserved in `all_sector_evidence_audit.csv`.
2. Federal records with action-date proxies remain **excluded** from retrospective
   performance tests. Ingestion `first_seen_utc` remains forward-only.
3. An optional `--evidence-file` contains event_id, published_at_utc,
   evidence_url, verified. The verified field is a claim from a trusted
   upstream verification process; H081 does **not** fetch or verify URL content.
   Thus, source authenticity must be established externally before use.
4. A reproducible SPY 200-session moving-average regime is calculated using
   completed daily closes. Regime labels become available at the previous
   session's 23:59 UTC for conservative next-session use.
5. An optional `--pit-market-cap-file` accepts historical cap observations
   with asof_date and available_at. No data file = no market-cap conclusions.
6. Fixed H078 chronological 60/20/20, 2x-cost, bootstrap and multiple-testing
   gates are reused; no search for favorable thresholds.
7. H081_REPORT.md and CSVs explicitly distinguish source-data gaps from
   failed statistical tests.

**Limitations:** SPY price histories may be revised/adjusted by the provider;
the regime analysis is exploratory until frozen historical price snapshots are
verified. This phase does not resolve unknown original publication timestamps
without independently verified source evidence. It cannot promise a profitable
signal, a final federal event effect, or a validated size effect absent PIT caps.

Run via Actions > H081 — Evidence and final research gates > Run workflow.
No production or live trading paths are modified.
